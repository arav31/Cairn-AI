# Cairn

Local landing page prototype for Cairn.

## Run

```bash
pnpm install
pnpm dev
```

The app runs at `http://localhost:3100`.

## Structure

- `apps/demo` - Next.js landing page.
- `packages/wavefield` - local WebGL visual engine used by the landing page.
- `docs/brand-guide.md` - local brand guide.
